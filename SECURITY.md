# Security policy

## Supported versions

Security fixes go into the latest release. Please upgrade to the newest version before reporting.

## Reporting a vulnerability

**Please don't open a public issue.** Report it privately through GitHub:

👉 [Report a vulnerability](https://github.com/shani8615/go-structllm/security/advisories/new)

Include what you found, how to reproduce it, and the impact you expect. You'll get an acknowledgement within a few days, and we'll agree on a disclosure date together once a fix is ready. Reporters are credited in the advisory unless they prefer otherwise.
